# Escape room workshop ideas

These small exercises use the game in `index.html`, `style.css`, and `game.js`. The main game is playable before you start.

## Beginner changes

1. **Change the room colors.** Update the colors in `drawRoom()`. Check that the door, floor, and walls remain easy to tell apart.
2. **Change a clue.** Edit one sentence in `clueText` and make the matching object count agree with the code.
3. **Add a fourth clue.** Add a clue row in the HTML, a clue spot and drawing in JavaScript, then extend the code display and keypad logic to four numbers.
4. **Add a friendly hint.** After a wrong code, show one gentle suggestion in the feedback area.

## Easy playtest

- Restart the game and check that clue progress and the timer reset.
- Click each glowing object and check the clue appears in its numbered row.
- Try the door before finding all clues; it should explain what to do next.
- Enter an incorrect code, then the clue numbers in order.
- Try both the on-screen keypad and keyboard.
- Narrow the browser window and confirm the room and keypad remain usable.
